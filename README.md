# Web Data Extraction and Analysis

## Project Overview

This project focuses on extracting and analyzing data from websites using Python and web scraping techniques. Book titles, prices, and ratings are collected from a website and organized for further analysis.

## What I Worked On

Used Requests and BeautifulSoup to extract book information from a website. Scraped 20 book records, cleaned and organized the extracted data using Pandas, and analyzed book prices and rating distributions. Finally, exported the results into a CSV file.

## Key Takeaway

Learned how web scraping helps collect real-world data from websites and transform it into meaningful information for analysis.

## Technologies Used

- Python
- Requests
- BeautifulSoup
- Pandas
- Matplotlib
- VS Code
